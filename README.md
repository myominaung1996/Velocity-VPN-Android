# Velocity VPN - Secure & High-Performance V2Ray Tunnel
<img width="886" height="1048" alt="1" src="https://github.com/user-attachments/assets/92bc74a2-8db6-4997-8467-e4aedca59a6f" />
Velocity VPN is a professional-grade tunneling tool for Android, built with Kotlin and Jetpack Compose. It is designed to protect your digital privacy and provide a secure internet connection using industry-standard V2Ray protocols.

## 🌟 Key Features

* 🚀 **Multi-Protocol Engine:** Supports VLess, VMess, Trojan, and WireGuard for maximum compatibility and speed.
* 🛡️ **Military-Grade Encryption:** Secure your network traffic from hackers and third-party tracking.
* 🚫 **Strict No-Logs Policy:** We do not collect, monitor, or store any of your browsing activities or traffic logs.
* 🛑 **Kill Switch:** Automatically blocks all internet traffic if the VPN connection drops, preventing data leaks.
* 🔀 **Split Tunneling:** Choose which apps use the VPN and which bypass it for local network access.
* ⚡ **Real-time Monitoring:** View live download/upload speeds and data usage directly in your status bar.
* 🎨 **Modern UI:** Built with Material 3, supporting Dark Mode and Dynamic Color (Material You).
* 🇲🇲 **Burmese Language:** Fully localized for Myanmar users.

## 📥 Download & Installation

You can download the latest version from the **[Releases](https://github.com/myominaung1996/Velocity-VPN-Android/releases)** section.

**How to choose the right APK:**
* **Universal APK:** Works on all Android devices (Largest size).
* **arm64-v8a:** Best for modern Android smartphones (Recommended).
* **armeabi-v7a:** For older Android devices.
* **x86 / x86_64:** For Android Emulators.
